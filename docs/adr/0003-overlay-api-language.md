# ADR-0003. overlay-api на Go

Статус: принято (2026-11-16). Подтверждает решение по умолчанию из ТЗ.

## Контекст

overlay-api — небольшой постоянно работающий сервис: раз в секунду опрашивает Prometheus, считает показатели, раздаёт снимок и поток SSE, отдаёт собственные метрики. Бюджет памяти — 32 МБ.

## Решение

Go, стандартная библиотека `net/http`, официальный клиент Prometheus для запросов и для собственных метрик. Образ собирается многоэтапно, итоговый слой — distroless или scratch.

Генератор синтетики `tools/synth` пишется на том же языке и использует OpenTelemetry Go SDK.

## Альтернативы

**Python + FastAPI.** Быстрее писать, удобнее для разовых скриптов. Образ в 100–200 МБ и 60–80 МБ памяти в простое съели бы заметную часть бюджета стека; для SSE нужен ASGI-сервер и аккуратная работа с отменой.

**Rust.** Позволил бы делить код с оверлеем на Tauri. Отклонён: время сборки и порог входа выше, а делить между сервисом и окном нечего, кроме схемы JSON.

## Почему так

- Один статический бинарник, образ около 15 МБ, память в простое 10–20 МБ.
- SSE, отмена по контексту и параллельные запросы делаются средствами стандартной библиотеки.
- Prometheus, коллектор, Loki, Grafana и Docker написаны на Go. Для роста в DevOps умение читать их исходники и писать экспортёры полезнее, чем ещё один сервис на Python.

## Дополнение по итогам фазы 2

Запросы к Prometheus выполняет собственный клиент на стандартной библиотеке (`internal/prom`, около 70 строк), а не официальный. Сервису нужен один вызов — мгновенный запрос; официальный клиент ради него привёл бы десяток зависимостей и свои типы данных. Собственные метрики, как и планировалось, отдаёт официальная библиотека `client_golang`.

Измерено: образ 15 МБ, память 8 МБ, сборка снимка около 20 мс.

## Последствия

- Go в WSL не устанавливается: сборка, тесты и линтер запускаются в контейнере через `make`. Это же гарантирует, что локальный прогон и CI используют одну версию.
- Unit-тесты используют фейковый Prometheus на `httptest`.
- Схема ответа `/api/v1/snapshot` описывается в одном месте и служит контрактом для оверлея.
